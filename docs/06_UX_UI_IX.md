# 06 - UX UI IX

Responsaveis: Norman, Tarcila, Myers e Ada

## Jornadas principais

1. Usuaria instala o app.
2. Le limites e privacidade.
3. Cria login.
4. Aceita termos essenciais.
5. Configura anjos.
6. Faz simulado obrigatorio.
7. Aciona alerta real quando necessario.
8. Cancela falso positivo se for seguro.
9. Acompanha estado de entrega.

## Fluxos obrigatorios

- Onboarding.
- Login.
- Home discreta.
- Rede de anjos.
- Convite.
- Consentimentos.
- Botao de panico.
- Alerta de teste.
- Configuracoes.
- Permissoes.

## Regras de interacao

- Texto curto.
- Comandos claros.
- Acoes destrutivas confirmadas.
- Cancelamento rapido.
- Feedback sem expor dado sensivel.
- Navegacao com uma mao.
- Acessibilidade com leitor de tela.

## Critérios de aceite UX

- Usuaria entende que o app nao substitui servicos oficiais.
- Usuaria consegue cadastrar anjo sem dado excessivo.
- Botao de panico exige gesto deliberado.
- Notificacao discreta nao expoe violencia ou endereco.
- Fluxo offline informa estado sem alarmismo.
